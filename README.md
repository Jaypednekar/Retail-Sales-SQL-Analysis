# Retail Sales Data Analysis Using MySQL

## Project Overview
This project focuses on cleaning and analysing retail sales data using MySQL. The goal is to understand sales performance, customer behaviour and business trends.

## Dataset
The dataset contains two tables:
- Orders
- Details

## Tools Used
- MySQL
- MySQL Workbench
- Kaggle Dataset

## Project Files
- `01_Data_Cleaning.sql` – Data cleaning, data type modification and data quality checks.
- `02_SQL_Analysis.sql` – 30 SQL queries covering business and sales analysis.

## Data Cleaning
- Checked table structure and data types.
- Checked missing and duplicate records.
- Checked date formats and data consistency.
- Checked matching order IDs between both tables.
- Established a foreign key relationship between Orders and Details.

## Business Analysis
- Overall sales, profit and quantity analysis.
- State-wise and city-wise sales.
- Category and sub-category performance.
- Customer purchase analysis.
- Monthly sales trends.
- Payment mode analysis.
- Profitability analysis.

## SQL Concepts Used
- SELECT, WHERE, GROUP BY and HAVING
- Aggregate Functions
- JOIN
- Subqueries
- CTEs
- Window Functions

## Project Objective
To practise SQL skills and analyse retail data to understand business performance and identify useful trends.
